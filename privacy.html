LowLife Publisher — Privacy Policy

Last updated: October 25, 2026

LowLife Publisher is a private automation tool of the LowLife project (github.com/avpersiyanov-afk/LowLife). It is used only by the owner of the LowLife channels to publish the project's own short videos to the project's own YouTube channel and Instagram account. It is not offered to other users.

What data the tool accesses

  • YouTube (YouTube API Services): the tool uploads videos to the owner's own YouTube channel (scope youtube.upload) and reads the basic information and statistics of that same channel (scope youtube.readonly) to confirm which channel it is signed in to.
  • Instagram / Meta: the tool publishes posts and reels to the owner's own Instagram account and reads that account's post statistics.

The tool does not access, collect or store data of any other users, viewers or channels.

How the data is stored

Access tokens are stored only on the owner's computer (Windows user environment variables) and are never sent anywhere except to the Google and Meta APIs they belong to. Post statistics are saved locally on the same computer for the owner's own analysis. Nothing is sold, shared or transferred to third parties.

YouTube API Services

LowLife Publisher uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. Access granted to the tool can be revoked at any time on the Google security settings page.

Deleting data

Revoking the tool's access (link above) stops all access immediately. Locally stored tokens and statistics are deleted by the owner on request.

Contact

Questions about this policy: open an issue at github.com/avpersiyanov-afk/LowLife/issues.

Кратко по-русски

LowLife Publisher — служебный инструмент проекта LowLife. Им пользуется только владелец, чтобы публиковать ролики проекта на собственные каналы YouTube и Instagram. Инструмент не получает и не хранит данные других людей; ключи доступа хранятся только на компьютере владельца и никому не передаются. Доступ можно отозвать в настройках безопасности Google.
